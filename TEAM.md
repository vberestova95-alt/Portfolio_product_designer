# Команда агентов

Роли общие (`~/.claude/agents/`), запуск `claude --agent <роль>` в этой папке. Новых агентов добавляет только
оркестратор и только после «да» пользователя. Правила этого проекта для docs-keeper — навык `.claude/skills/docs-keeper-guide`.
Правила кейса (каркас из 8 секций, картинки, пайплайн выкатки, чек-лист полноты) — навык `.claude/skills/case-guide`; загружают editor, designer, researcher и docs-keeper при работе над кейсом.

## Как роли общаются

`SendMessage` по имени сессии; первое слово — тип:
- `ЗАДАЧА <пункт>` — оркестратор → исполнителю: бриф, разрешённые файлы, критерий готовности.
- `ГОТОВО <пункт>` — исполнитель → оркестратору (и design-sync для интерфейса): файлы, проверки, что не проверено.
- `СВЕРКА <пункт>` — design-sync → оркестратору: совпадает / расхождения и выбор пользователя.
- `ЗАПРОС` — любая роль → оркестратору: задача, макет, исследование, новый агент.
- `ЗНАНИЯ` — docs-keeper → любой роли: что узнали и решили, с источниками.

Напрямую роли друг другу задачи не ставят — только через оркестратора.
