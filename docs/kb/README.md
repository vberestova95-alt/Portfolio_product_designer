# База знаний: Portfolio — Product Designer

| Файл | Что там | Кто обновляет |
| --- | --- | --- |
| context.md | Цель, пользователи, статус, стек, ссылки, текущий фокус | недельная чистка, при крупных изменениях |
| decisions.md | Решения: что, почему, альтернативы, источники | саммари сессии |
| sources.md | Ссылки на референсы, статьи, Figma, обсуждения | саммари сессии |
| sessions/YYYY-MM.md | Короткие саммари сессий | /kb-session-summary |

Правила:
- Каждое решение — с причиной и ссылкой на источник (URL, Figma, файл:строка, коммит, сообщение пользователя с датой).
- Пишем коротко: факты, числа, ссылки. Без пересказа кода — код и git уже это хранят.
- Устаревшее не удаляем, а переносим в archive/ при недельной чистке.
