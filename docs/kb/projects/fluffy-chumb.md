## Коротко
- Начало — веб-трекер инсулина для кота-диабетика (Pet Diabetes Tracker / My Fluffy Friend). Код писал Валера
  (Valeriy Eisele, GitHub stenvl), все 16 коммитов веб-фронтенда его; бэкенд у него же (Go + DynamoDB + Cognito). Источник: web-kb `context.md`.
- Октябрь 2026: редизайн и переход к мобильному приложению Fluffy Chumb (Expo, iOS + Android): трекеры как набор
  инструментов, общий список дел на день для семьи.
- Сейчас (30.10): MVP мобильного приложения собран и стоит на iPhone пользователя (Release-сборка, данные из мок-сервера); TestFlight и сторов нет;
  лендинг беты fluffychumb.com собирает заявки.

## Что есть в MVP сейчас (по коду и бэклогу, 30.10)
- Вкладки Home · Trackers · Journal (History) · Family; онбординг язык → питомец → трекер; RU и EN.
- Трекеры: Insulin (карта уколов на фото спины или силуэте), Glucose, Mood, свой трекер — конструктор в 4 шага
  (категория, поля число / шкала / да-нет / заметка, вид: плитка, форма, мех, ритм и напоминания).
- Рутина дня: отметка одним тапом (у задач без формы), «Не сейчас» (отложить / пропустить с причиной), кружок «кто отметил».
- Family: приглашение по email без выбора роли; в списке роли Owner / Can edit.
- Напоминания — локальные на этом телефоне; push нет (Personal Team).
- History: 7 / 30 дней / свои даты, графики, экспорт — текстовая сводка и CSV.
- Нет: ответственный за задачу, временный доступ ситтера на даты, push семье, шаблоны действий, TestFlight.

### Ответы пользователя, 2026-10-30
1. **Интервью** — на этапе тестирования веб-MVP: мы сами как пользователи и кот Лютик, с которого всё началось; 2 интервью с владельцем кота с диабетом; несколько демо другим людям — им функции были не актуальны. Интервью по плану от 28.10 (6–8) — не проводились (не упомянуты).
2. **12** — потенциальные бета-тестеры, собраны с лендинга; ещё ничего не тестировали.
3. **Роль второго участника** — «бэкенд-инженер», имя в кейсе не указывать.
4. **Стек** — можно указать (Expo / React Native, Figma, Claude Code с командой агентов).
5. **Ситтер** — важная часть аудитории. Вместо одной «семьи» — сегменты: семьи с асинхронным уходом; когда за питомцем смотрят другие (отпуск, ситтер); люди, которые любят отслеживать показатели здоровья; у кого много животных; болеющие питомцы со сложным протоколом; котята и щенки — рутина только начинается; семьи с детьми, которые учат детей заботиться о питомце. По каждому — проблема → как решает приложение → какими функциями (BACKLOG п. 5).
6. **Бета** — тестирование в первой половине ноября 2026; сейчас ждём бэкенд.
